# Bien Vêtu

Guide d'achat de vêtements : matières conseillées pour chaque vêtement (et pourquoi), et tier lists de marques par budget.

Site statique (HTML/CSS/JS, sans dépendance), hébergé sur GitHub Pages.

## Modifier le contenu

Tout le contenu (vêtements, matières, marques) se trouve dans `data.js`.

## Tester en local

Ouvrir `index.html` dans un navigateur.
